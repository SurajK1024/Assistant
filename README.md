# Agentic AI Assistant

This project is focused on developing an agentic AI assistant that can help users by reminding them of important tasks and assisting with various activities. The AI is designed to be proactive, understanding user needs and providing timely reminders and support.

## Features
- Proactive task reminder
- Set reminders for tasks and events
- Assist with scheduling and oraganizing events
- Natural language understanding for better interaction
- Suggest gift for the upcoming events
- integrate with calender and to-do list from app
- Customize the notifications
- Notify upcominf events via notifications or mails

## Tools and APIs
- LLM for natural language processing
- Calendar API for scheduling
- Notification API for sending reminders
- Task management API
- Gift suggestion API
- Database connection API


## Database
- Reminder Database: Store user reminders and tasks

## Agentic AI Workflow
1. User Interaction: Text
2. Orchestration: Agentic AI Framework
3. Tools: LLM, Calendar API, Notification API, Task Management API, Gift Suggestion API
4. Database: Reminder Database

## Getting Started
To get started with the Agentic AI Assistant, follow these steps:
1. Clone the repository
2. Install the required dependencies
3. Set up API keys for the necessary services
4. Run the application and start interacting with the AI assistant
5. Customize settings and preferences as needed
